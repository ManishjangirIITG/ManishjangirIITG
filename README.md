### 🚀 Featured Projects

#### 🧬 Molecular Spectra Prediction via Graph Neural Networks
*Research — B.Tech Thesis, IIT Guwahati*
`PyTorch Geometric` `RDKit` `FastAPI` `Docker` `MPNN`
- Designed a custom Message-Passing Neural Network to predict NMR/IR spectra directly from molecular topology
- Built a SMILES-to-graph preprocessing pipeline with RDKit, validating 250,000+ molecules at 100% input integrity
- Shipped a stateless FastAPI inference microservice sustaining 400 req/s at 43ms P95 latency
- Cut Docker image size by 60%+ via multi-stage builds

#### 🎬 UR VDO — Full-Stack Video Streaming Platform
`Next.js` `React` `MongoDB` `FFmpeg` `TailwindCSS`
- Built a full-stack video platform with JWT authentication and adaptive bitrate streaming (480p–1080p) via FFmpeg
- Integrated Razorpay for subscriptions with webhook-driven invoice generation and transactional email
- Designed indexed MongoDB schemas achieving sub-40ms query latency across 10,000+ record datasets
- Implemented geolocation-aware OTP delivery, routing verification via SMS or email based on user location

#### 📈 Crypto Price Prediction — ML Forecasting System
`Python` `XGBoost` `Scikit-learn` `Time Series`
- Engineered 12+ features from 36+ months of BTC price data and Wikipedia edit activity
- Built a Random Forest baseline, then an XGBoost model, lifting directional forecasting accuracy to 52.8%
- Developed a backtesting system to simulate real trading performance
